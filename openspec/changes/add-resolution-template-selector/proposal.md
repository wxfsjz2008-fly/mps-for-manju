## Why

当前漫剧视频增强系统只使用单一的固定转码模版，用户无法根据实际需求选择不同分辨率的输出。不同场景下用户可能需要不同质量的输出：
- **4K 超高清**：适合大屏播放、高端设备展示
- **2K 高清**：平衡画质与文件大小，适合大多数场景
- **1080P 全高清**：文件较小，适合移动设备和快速分享

通过添加分辨率模版选择功能，用户可以根据实际需求选择最合适的转码模版，提升系统的灵活性和实用性。

## What Changes

- 前端新增分辨率模版选择组件，用户在上传视频前可以选择目标输出分辨率
- 新增三个转码模版选项：
  - **4K 超高清** (模版ID: 327008) - 漫剧场景-大模型增强-MP4-4K-帧率随源
  - **2K 高清** (模版ID: 327006) - 漫剧场景-大模型增强-MP4-2K-帧率随源
  - **1080P 全高清** (模版ID: 327004) - 漫剧场景-大模型增强-MP4-1080P-帧率随源
- 后端 MPS 服务支持接收动态模版 ID 参数
- 任务创建时记录用户选择的模版信息

## Capabilities

### New Capabilities

- `resolution-template-selector`: 分辨率模版选择组件，支持用户选择 4K/2K/1080P 三种输出分辨率

### Modified Capabilities

- `video-upload`: 修改上传流程，在提交 MPS 任务时传递用户选择的模版 ID
- `video-enhancement`: 修改 MPS 任务提交逻辑，支持动态模版 ID
- `task-management`: 任务表新增字段记录选择的模版信息

## Impact

- **前端影响**：
  - VideoUploader 组件需要添加模版选择 UI
  - API 调用需要传递模版 ID 参数
- **后端影响**：
  - MPS 路由需要接收模版 ID 参数
  - MPS 服务需要支持动态模版 ID
  - 任务服务可选择记录模版信息（便于追溯）
- **数据库影响**：可选新增 template_id 字段到任务表
- **配置影响**：移除原有固定的 enhanceTemplateId 配置，改为前端动态选择
