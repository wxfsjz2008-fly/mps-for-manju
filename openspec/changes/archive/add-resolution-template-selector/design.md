## Context

当前漫剧视频增强系统已完成基础功能，包括视频上传、MPS 增强处理和视频对比播放。现在需要在此基础上添加分辨率模版选择功能。

**当前状态**：
- 前端 VideoUploader 组件已实现文件上传和自动增强选项
- 后端 MPS 服务使用固定的 `config.mps.enhanceTemplateId` 配置
- 任务表不记录模版信息

**约束条件**：
- 必须使用腾讯云 MPS 的指定模版 ID
- 需要保持向后兼容，默认使用 2K 模版
- UI 变更需要与现有设计风格保持一致

**利益相关者**：
- 漫剧内容创作者：根据需求选择合适的输出分辨率

## Goals / Non-Goals

**Goals:**
- 提供直观的模版选择 UI，用户可以选择 4K/2K/1080P 三种分辨率
- 后端支持动态模版 ID，根据前端传参调用不同的 MPS 模版
- 显示每个模版的简要说明，帮助用户做出选择

**Non-Goals:**
- 不支持自定义模版参数（只使用预设模版）
- 不支持同时处理多个分辨率版本
- 不实现模版预览功能

## Decisions

### 1. 模版配置

| 分辨率 | 模版ID | 模版名称 | 说明 |
|--------|--------|----------|------|
| 4K | 327008 | 漫剧场景-大模型增强-MP4-4K-帧率随源 | 适合大屏播放 |
| 2K | 327006 | 漫剧场景-大模型增强-MP4-2K-帧率随源 | 推荐，平衡画质与大小 |
| 1080P | 327004 | 漫剧场景-大模型增强-MP4-1080P-帧率随源 | 适合移动端 |

### 2. 默认值选择

**方案**：默认选择 2K (327006)
- **理由**：2K 分辨率在画质和文件大小之间取得较好平衡，适合大多数场景

### 3. UI 设计

**方案**：在 VideoUploader 组件的"自动增强"选项下方添加分辨率选择器
- 使用单选按钮组（Radio Group）展示三个选项
- 每个选项显示分辨率标签和简要说明
- 仅在"自动增强"开启时显示选择器

**设计稿**：
```
┌─────────────────────────────────────────┐
│ ☑ 上传后自动开始增强处理                   │
│                                         │
│   选择输出分辨率：                         │
│   ○ 4K 超高清   适合大屏播放              │
│   ◉ 2K 高清     推荐，平衡画质与大小       │
│   ○ 1080P      适合移动端                │
└─────────────────────────────────────────┘
```

### 4. API 设计

**修改 POST /api/mps/submit 接口**：

请求体新增 `templateId` 参数：
```json
{
  "taskId": "xxx",
  "templateId": 327006  // 可选，默认 327006
}
```

### 5. 数据流

```
用户选择模版 → 前端保存选择 → 上传完成后调用 mpsApi.submit(taskId, templateId) 
→ 后端接收 templateId → MPS 服务使用该 templateId 提交任务
```

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|----------|
| 用户不了解各分辨率区别 | 提供简要说明文字，标记推荐选项 |
| 4K 输出文件过大 | 在 4K 选项旁提示文件可能较大 |
| 模版 ID 变更 | 将模版配置集中定义，便于后续维护 |
