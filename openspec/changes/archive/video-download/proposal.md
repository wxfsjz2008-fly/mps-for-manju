## Why

目前漫剧视频增强系统只支持在线预览和对比播放，用户无法将处理后的高清视频下载到本地。这带来了以下问题：
- **内容分发受限**：用户无法方便地将增强后的视频用于其他平台发布
- **离线观看需求**：部分用户需要在没有网络的环境下观看或编辑视频
- **资产留存**：用户希望能够保存处理后的视频文件作为永久资产

通过添加视频下载功能，用户可以将高清处理后的视频下载到本地，提升系统的完整性和实用性。

## What Changes

- 前端任务详情页新增下载按钮，支持用户下载增强后的视频
- 后端新增下载接口，生成带有下载 Content-Disposition 头的签名 URL
- 下载过程中显示友好的状态提示
- 支持自定义下载文件名（保留原始文件名并添加"_增强"后缀）

## Capabilities

### New Capabilities

- `video-download`: 视频下载功能，支持用户将增强后的视频下载到本地设备

### Modified Capabilities

- `task-detail-page`: 修改任务详情页面，添加下载按钮和下载状态提示

## Impact

- **前端影响**：
  - TaskDetailPage 组件需要添加下载按钮和下载逻辑
  - API 服务需要新增获取下载 URL 的接口调用
  - 需要处理下载进度显示和错误提示
- **后端影响**：
  - Upload 路由需要新增下载 URL 生成接口
  - 签名 URL 需要包含 Content-Disposition 头以触发浏览器下载
- **用户体验影响**：
  - 用户可以更方便地获取处理后的视频资产
  - 提供明确的下载状态反馈
